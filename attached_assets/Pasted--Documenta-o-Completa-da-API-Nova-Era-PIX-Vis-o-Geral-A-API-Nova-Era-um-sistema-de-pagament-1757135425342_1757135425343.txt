## Métodos Disponíveis

### 1. Autenticação

```python
def _get_auth_token(self) -> str:
    """Gera token de autenticação Basic Auth"""
    credentials = f"{self.secret_key}:{self.public_key}"
    token = base64.b64encode(credentials.encode()).decode()
    return f"Basic {token}"
```

### 2. Requisições HTTP

```python
def _make_request(self, method: str, endpoint: str, data: Optional[Dict] = None) -> Dict[str, Any]:
    """Faz requisição para a API"""
    url = f"{self.base_url}{endpoint}"
    
    headers = {
        "Content-Type": "application/json",
        "Authorization": self._get_auth_token()
    }
    
    # Suporta GET e POST
    if method.upper() == "POST":
        response = requests.post(url, json=data, headers=headers, timeout=30)
    elif method.upper() == "GET":
        response = requests.get(url, headers=headers, timeout=30)
    else:
        raise ValueError(f"Método HTTP não suportado: {method}")
    
    response.raise_for_status()
    return response.json()
```

### 4. Consultar Status da Transação

```python
def get_transaction_status(self, transaction_id: str) -> Dict[str, Any]:
    """
    Consulta o status de uma transação
    
    Args:
        transaction_id: ID da transação
    
    Returns:
        Dict: Dados da transação
    """
    
    response = self._make_request("GET", f"/transactions/{transaction_id}")
    
    if response.get("success"):
        return response["data"]
    else:
        error_msg = response.get("error", {}).get("message", "Erro desconhecido")
        raise Exception(f"Erro da API: {error_msg}")
```

## Endpoints da API

### POST /transactions
**Descrição**: Criar nova transação PIX

**Headers**:
```
Content-Type: application/json
Authorization: Basic {base64(secret_key:public_key)}
```

**Body**:
```json
{
    "customer": {
        "name": "Nome do Cliente",
        "email": "email@exemplo.com",
        "phone": "(11) 99999-9999",
        "document": {
            "number": "12345678901",
            "type": "cpf"
        }
    },
    "items": [
        {
            "tangible": false,
            "quantity": 1,
            "unitPrice": 8740,
            "title": "Taxa de Inscrição"
        }
    ],
    "postbackUrl": "https://webhook.site/your-webhook-url",
    "amount": 8740,
    "paymentMethod": "pix"
}
```

### GET /transactions/{id}
**Descrição**: Consultar status de uma transação

**Headers**:
```
Authorization: Basic {base64(secret_key:public_key)}
```

## Status da Transação

- `pending`: Aguardando pagamento
- `paid`: Pagamento confirmado
- `expired`: Transação expirada
- `failed`: Falha no pagamento

## Tratamento de Erros

- **ValueError**: Para métodos HTTP não suportados
- **requests.exceptions.RequestException**: Para erros de rede
- **json.JSONDecodeError**: Para erros de decodificação JSON
- **Exception**: Para erros gerais da API

## Observações Importantes

1. **Valores em centavos**: Todos os valores monetários devem ser enviados em centavos (ex: R$ 87,40 = 8740)
2. **CPF**: Deve ser limpo de pontos e hífens antes do envio
3. **Timeout**: Requisições têm timeout de 30 segundos
4. **Webhook URL**: Configure uma URL válida para receber notificações de pagamento
5. **QR Code**: O campo `qrcode` na resposta contém o código PIX completo
